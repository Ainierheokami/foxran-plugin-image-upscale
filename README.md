# 图片放大（foxran-plugin-image-upscale）

Foxran Agent 工具插件：输入一张图，输出高清大图。适合 GPT Image 2 生成后排版合适、但单图分辨率低导致细节发糊、文字乱码的图片。

## 原理

1. **甜点尺寸切块**：按放大倍率算出输出尺寸，从 `tile_sizes`（默认 1024x1024 / 1536x1024 / 1024x1536）里挑块数最少的一种，相邻块保留约 15% 冗余。
2. **逐块重绘**：每块先插值放大到该块的请求尺寸，再交给图像编辑模型（推荐 `gpt-image-2`），要求保持构图不变、画清细节、修正乱码文字。可以传 `text_hint` 告诉模型文字的正确内容。
3. **对齐（只在需要时）**：GPT Image 2 通常会保持画布位置不变，这时不做任何变换，避免重新采样把图弄软。只有检测到整块平移或伸缩超过 1 像素时，才用 SIFT 特征点 + RANSAC（ECC 细化）把它对回去；位移中位数达到 3 像素时，再用平滑光流修正局部挪动。
4. **只纠正真正的错位**：在比字形更粗的尺度上比较模型图和原图的结构（局部相关性）。颜色更鲜艳、天空更亮、乱码被改成正确的字，都不算偏差；只有成片的内容挪位、消失或凭空出现，才会重绘一次，仍不行就用原图插值填补那一片。整块对不齐时，整块退回插值。
5. **拼缝与校色**：在冗余区里用动态规划找两块差异最小、而且都和原图一致的路径作为拼缝。每块只拟合一个整体的颜色变换（各通道一个增益和偏移）来消除模型的偏色；拼好后再在很粗的尺度上按原图做一次亮度校正。两步都不会把原图的内容画回去，因此不会产生重影。

某块重试后仍失败时用普通插值顶上，结果里会注明；透明通道单独插值后保留。

## 工具

`image_hd_upscale(path, scale=2, text_hint="")`

- `path`：本地路径、http(s) URL 或 `url-<uuid>` 引用
- `scale`：1~4；只修乱码不放大时传 1
- `text_hint`：图中文字的正确内容（可选）

## 命令

插件自带直通命令，装好后会出现在设置页“命令策略”里，默认开启：

```
/放大 [图中文字的正确内容]   （附带图片，或引用一条带图片的消息）
```

也可以用 `/高清`、`/upscale`。命令后面的文字会作为 `text_hint` 传给模型。

块数超过 `max_tiles` 或输出像素超过 `max_output_pixels` 时会自动降低倍率。

## 配置

首次加载时生成 `config/image_hd_upscale.yaml`，各项说明见 [config_template.yaml](config_template.yaml)。最常改的是 `model_name`：填 models.yaml 里 gpt-image-2 的模型名；留空则按 `image_edit` 标签轮询。

## 排查

结果里会说明哪些块用原图插值填补了多少。想看每块的具体情况，把配置里的 `save_tiles` 设为 `true`，每块的模型原图、修正后的结果和填补区域会保存到 `tmp/image_hd_upscale/debug/<时间>/`。

## 依赖

宿主自带的 Pillow、numpy、opencv-python；宿主版本 >= 4.5.0。

## 测试

在宿主仓库根目录运行：

```bash

```
